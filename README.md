\# 🐦 Flappy Bird Clone (Unity)



A simple and polished clone of the classic \*\*Flappy Bird\*\* game, built using the Unity engine.

This project focuses on core game mechanics, smooth physics, and clean code structure.



\---



\## 🎮 Gameplay Preview

🎥 Demo Video:

https://drive.google.com/file/d/1WINsMOmKXnnH45FjE-4KgQmDZl1wGBV0/view?usp=sharing



\---



\## 🚀 Features



\* Smooth bird movement with physics-based controls

\* Infinite scrolling obstacles

\* Score tracking system

\* Collision detection and game over logic

\* Restart system

\* Clean and modular C# scripts



\---



\## 🛠️ Built With



\* Unity (Game Engine)

\* C# (Programming Language)



\---



\## 📂 Project Structure



```bash

Assets/            # Game assets, scripts, scenes

ProjectSettings/   # Unity project settings

Packages/          # Dependencies

```



\---



\## ▶️ How to Run



1\. Download or clone the repository

2\. Open the project in Unity Hub

3\. Click \*\*Play\*\* in the Unity Editor
